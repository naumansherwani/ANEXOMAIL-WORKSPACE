# RULE 52 COMBO LAW (24 Nov 2026 11:2x PKT)
Rule 52 now carries FOUR web-researched standards as ONE combo. Every phase of the founder, awam and Desk blueprints is built with the letters that apply to it, and its contract in docs/claude/tech-contracts/CURRENT.md MUST say so (line `RULE 52 COMBO: S=yes|N/A (reason) M=yes|N/A (reason) L=yes|N/A (reason)`); the gate "RULE 52 COMBO" stops a commit without it.
- S = SIGNED SERVICE CALLS = RFC 9421 HTTP Message Signatures (https://www.rfc-editor.org/rfc/rfc9421) + IETF WIMSE workload-to-workload HTTP signature draft (https://datatracker.ietf.org/doc/html/draft-ietf-wimse-http-signature). In code: each service signs with its OWN Ed25519 key; the signed body carries issued_at / expires_at (60 s), a request id (nonce, replay cache), the key id, the audience (tag) and the EXACT path (covered request target); a closed field list; the answer is signed by the other side's own key, bound to the request id, fresh (15 s); HTTP/3 only (TLS 1.3, AES-256-GCM, X25519MLKEM768). Reference code: control-plane/src/resolve.rs + docs/claude/admin-desk/server/src/resolve_cp.rs. Honest open gap: ML-DSA hybrid (GAP 2).
- M = MAIL SENDER IDENTITY = RFC 7489 DMARC identifier alignment (https://datatracker.ietf.org/doc/html/rfc7489). In code: a sender is trusted as a domain only if SPF or DKIM passed AND the authenticated domain aligns with the From domain; the fact travels as a REQUIRED real boolean, never defaulted; an unaligned or shared-provider sender never resolves to a company. Reference: AD31.sql.
- L = LOGGING = OWASP Logging Cheat Sheet (https://cheatsheetseries.owasp.org/cheatsheets/Logging_Cheat_Sheet.html). In code: log who / what / when / outcome for FAILURES as well as successes, in the tamper-evident hash-chained ledger; NEVER personal data or secrets (the writer has no parameter that could carry an address, a name or a password); no action without its line (if the line cannot be written, the result is not used). Reference: AD32.sql.
- WHEN A LETTER DOES NOT APPLY the contract says `N/A (reason)`, e.g. a pure screen phase: S=N/A (no service call) M=N/A (no mail identity) L=N/A (no action to record). A bare N/A is refused by the gate.
- Versions are never old: every phase re-checks tokio, axum, quinn, h3 with `cargo search` and the lock file (his 24 Nov rule).
Law file: docs/claude/RULE-52-COMBO-LAW-24NOV.md. Gate: rules-gate.py rule "RULE 52 COMBO" (law file + the four sources + blueprint markers + the newest contract line).
