Relationships x Memory - 7 advanced features (buyer ki nazar se)
This is the original spec written by the owner. Do not shorten or reinterpret it.

1. Unified timeline per person - is banda ke sath jo bhi hua (email, meeting, task, promise, deal) - sab ek hi jagah, chronological order mein. Abhi ye sab alag pages mein bikhra hai.
2. Relationship health signal - "Last contact 45 din pehle" + saaf indicator: Active / Thanda ho raha hai / Cold. Isse turant pata chale kaunsa rishta kamzor ho raha hai (Follow-ups se related, lekin person-level, thread-level nahi).
3. Response-pace stats per person - ye banda mujhe kitni der mein reply karta hai, main isay kitni der mein karta hoon (Thread Insights jaisa, lekin poore contact ka aggregate, sirf ek thread ka nahi).
4. Auto-extracted facts - email signature se job-title, company, phone number khud nikal aaye - koi manual typing nahi (Gmail bilkul ye nahi karta).
5. Team-wide shared context (sirf Business) - agar koi teammate bhi is banday ko email kar chuka hai, wo bhi yahin dikhe - taake do log ek doosre se contradict na karein ya dobara wahi baat na karein.
6. Person-level notes (thread se alag) - "hamesha bachon ke baare mein pucho", "WhatsApp pasand karta hai email se zyada" - ye note har future conversation mein yaad rahe, sirf ek thread tak mehdood na ho.
7. Merge duplicate identities - agar wahi banda 2 alag email addresses (personal + office) se email kare, unhe ek hi Memory record mein jod sakein, taake history bikhre na.

Owner's rule: the real buyer must only ever see their own real data. Never run write-tests on real or family accounts (Masood, Humza) without explicit permission.
